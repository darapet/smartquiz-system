      Quick guide

      Multiplayer rules

      • Answer each question before its timer reaches zero.
      • The first player to answer correctly earns 5 points.
      • You get one answer per question. Once submitted, your answer is locked.
      • The correct answer is revealed when the timer ends.
      • The host controls when the next question starts.
      • If you join after the game starts, you enter the live game and can answer the current question if time remains.
